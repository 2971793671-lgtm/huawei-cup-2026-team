# 文献管理规范

## 单一事实源

论文实际引用的 BibTeX 条目统一维护在 [paper/refs.bib](../../paper/refs.bib)。三名成员都从这个文件读取和提交引用，禁止在各自设备上维护互不相同的 `.bib` 副本。

模板附带的 [paper/template/reference.bib](../../paper/template/reference.bib) 只用于展示模板写法，不作为本项目的参考文献库。

## 目录边界

| 内容 | 位置 | 是否提交 Git |
|---|---|---|
| 论文实际引用条目 | `paper/refs.bib` | 是 |
| 文献检索式、筛选记录、阅读笔记 | `docs/literature/` | 是，但只提交可公开内容 |
| 版权允许再分发的附件 | 经确认后单独登记 | 视许可而定 |
| 期刊 PDF、下载缓存、个人批注 | 各成员本地文献库 | 默认不提交 |

公开仓库中不得放入未获再分发许可的整篇论文、学校订阅下载内容、个人账号信息或访问令牌。需要让队友复现时，在笔记中记录标题、作者、年份、DOI/URL、检索日期和页码，而不是上传受版权保护的 PDF。

## 条目要求

每个条目至少包含：

- 稳定的 cite key，例如 `zhang2026baseline`；
- 作者、标题、出处和年份；
- DOI、官方 URL 或其他可核验定位信息；
- 与论文论断直接相关时，补充页码、章节或数据集版本。

添加条目前先搜索 `paper/refs.bib`，避免同一文献出现多个 cite key。修改条目时使用短分支并由另一名成员检查作者、年份、标题、DOI 和正文引用是否一致。

## 论文引用流程

```text
检索/阅读 → docs/literature/笔记 → paper/refs.bib → 正文 \cite{...}
→ XeLaTeX/BibTeX 编译 → 检查未引用和缺失引用 → PR 审阅
```

参考文献的排序和格式由 `paper/main.tex` 中的 `template/gmcm` 样式统一控制，不在章节文件中手工排版参考文献。
