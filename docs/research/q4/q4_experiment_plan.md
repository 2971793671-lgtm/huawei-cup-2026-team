# 问题四实验计划

## 研究目标

在明确模型类型、时间口径和开源筛选口径后，用附件 C 的逐任务 Benchmark 分数与模型规模信息，检验以下两个问题：

1. 控制参数量、训练数据量和训练算力后，是否仍存在稳定的时间/技术进步效应；
2. 在给定未来算力增长情景下，未来 12/24 个月的能力前沿如何变化。

## 数据审计与同质性检查

1. 以模型家族/模型名作为聚类单位，去除同一模型的重复提交和重复 revision；
2. 统一时间轴，主分析使用 `Submission Date`，年度数据只用于描述性检查；
3. 区分 pretrained、chat/finetuned、merge 等模型类型，并分别检查参数量、Benchmark 分数和时间分布；
4. 使用 C8 逐任务结果，按 IFEval、BBH、MATH、GPQA、MUSR、MMLU-PRO 聚合，综合分采用任务组等权；
5. 检查每个时间段的样本数、重复率、缺失率和任务评测口径；
6. 对高可比和中等可比的 Loss–Benchmark 桥接样本分别分析，传播桥接误差。

## 基线实验

由于年度时间点很少，先以月度 95% 分位数作为前沿指标，进行滚动一步预测，比较：

- 最近一期持平（naive-last）；
- 最近三期均值（mean-last-3）；
- 扩展窗口线性趋势（expanding linear trend）。

评价指标为 MAE、RMSE 和平均偏差；方向命中率只作为补充描述，因为持平基线没有方向预测。验证按时间顺序进行，禁止随机划分。

基线主目标使用 C8 逐任务详细结果构造的六任务组等权分数；Leaderboard 的 `Average` 作为口径敏感性分析。2019--2023 的历史行与 2024--2025 的 Open LLM Leaderboard 存在明显数据源断点，主分析不将它们混合。

## 主模型与稳健性模型

主模型拟采用带模型类型和模型家族层级效应的低复杂度面板分位数模型：

`Q_tau(S) = alpha + beta_N log(N) + beta_D log(D) + beta_C log(C) + gamma*time + type + family`

其中 `tau` 取 0.90/0.95。稳健性模型包括随机前沿模型、低自由度 GAM，以及只在模型家族内比较的固定效应模型。

## 严格证伪

1. 留一时间段滚动预测；
2. 留一模型家族验证；
3. 打乱年份标签的安慰剂检验；
4. 留出任务组检验；
5. 改变任务权重、模型类型筛选、开源口径和时间定义；
6. 检查技术进步系数的符号、效应量和区间是否稳定；
7. 使用模型家族聚类 bootstrap，不把同一模型族的多行记录当成独立样本。

只有当效应在主要规格、时间留出和敏感性分析中方向一致，才报告存在稳定的非规模技术进步；否则报告证据不足。
