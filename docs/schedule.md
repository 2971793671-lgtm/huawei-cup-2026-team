# 工作节奏

## 赛前

- 完成三台设备的 Git、Python 和 XeLaTeX 环境检查。
- 用往年题进行一次从数据到 PDF 的完整演练。
- 测试 clean clone 后能否编译论文并运行基线。
- 建立队员联系方式、设备名称和备份位置清单。

## 比赛中

1. 读题：形成 `docs/problem/problem-brief.md`。
2. 基线：先得到可运行、可解释的最低方案。
3. 并行实验：每次运行生成唯一 `run_id`。
4. 模型冻结：停止无效探索，锁定模型、数据和结果。
5. 论文集成：先摘要和结果，再统一语言、图表和引用。
6. 封卷：双人复核后生成 PDF、SHA256 和 MD5 记录。

## 关键原则

提交论文 MD5 后不得再修改对应 PDF。任何紧急修复都必须重新生成 PDF、重新检查并重新计算校验值。
