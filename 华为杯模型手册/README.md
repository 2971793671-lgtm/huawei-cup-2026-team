# 华为杯模型学习与竞赛速查手册

这份手册服务两个目标：

1. 新手先理解模型解决什么问题，再学习核心思想和最小代码。
2. 比赛时按“数据类型 + 任务”快速找到基线、升级路线和常见坑。

## 使用方式

- 学习时：每周只完成一个任务模块，并用一个小数据集复现最小例子。
- 比赛时：先看“任务路由表”，跑通基线，再决定是否升级模型。
- 写论文时：从模型卡片复制“假设、优点、局限、评价指标、参考文献”。
- 每张卡片只回答七个问题：解决什么问题、输入输出是什么、核心直觉、什么时候用、什么时候不用、最小代码、常见错误。

## 任务路由表

| 看到的数据/问题 | 第一版基线 | 常见升级 | 优先检查 |
|---|---|---|---|
| 表格 + 连续值预测 | 均值/线性回归、随机森林 | XGBoost、LightGBM、CatBoost、集成 | 缺失值、异常值、数据泄漏、交叉验证 |
| 表格 + 类别预测 | 多数类/逻辑回归 | GBDT、XGBoost、LightGBM、CatBoost | 类别不平衡、F1/AUC、阈值 |
| 单变量/多变量时间序列 | 持续性预测、季节性基线、ARIMA/ETS | 滞后特征 + GBDT、TCN、LSTM、Transformer | 时间切分、滚动验证、未来信息泄漏 |
| 图像分类/回归 | 预训练 CNN | ResNet/EfficientNet、ViT/Swin | 增强、类别不平衡、迁移学习 |
| 文本分类/相似度 | TF-IDF + 线性模型 | 预训练 BERT/embedding + 线性层 | 分词、标签泄漏、长文本截断 |
| 节点/边/图预测 | 统计特征 + 传统模型 | GCN、GraphSAGE、GAT | 图划分、邻居泄漏、图结构是否可信 |
| 聚类/降维 | PCA + K-means | GMM、DBSCAN、UMAP | 标准化、距离度量、簇数解释 |
| 约束下的排程/选址/分配 | 线性规划/整数规划 | 启发式、遗传算法、粒子群、模拟退火 | 目标函数、约束完整性、可行解 |
| 缺失值/不确定性 | 插值、多重插补、分位数回归 | 深度插补、扩散模型、保序/保覆盖预测区间 | 缺失机制、区间覆盖率、外推风险 |

## 新手四周路线

### 第 1 周：把一个问题跑通

Python、NumPy、pandas、可视化、训练/验证/测试划分；完成线性回归、逻辑回归、决策树和随机森林。重点不是背 API，而是会说明目标变量、特征、评价指标和数据切分方式。

### 第 2 周：掌握竞赛最常用的强基线

学习 GBDT 家族：XGBoost、LightGBM、CatBoost。理解“许多棵弱树逐步修正误差”的直觉，比较特征工程、交叉验证和简单集成带来的收益。

### 第 3 周：按题型学习序列、图和深度模型

时间序列先学季节性基线、ARIMA/ETS 和滞后特征，再看 TCN、LSTM、Transformer；图数据看 GCN/GraphSAGE/GAT；图像看 CNN 与迁移学习。每类只保留一个可运行的小例子。

### 第 4 周：理解近年热门方向

Transformer/注意力、Vision Transformer、图神经网络、扩散模型、基础模型、LoRA/PEFT、RAG、自监督学习。这个阶段的目标是会解释“它为什么可能有效、代价是什么、比赛中何时值得用”，而不是从零训练大模型。

## 热门模型的最低理解标准

### Transformer / 注意力

把输入元素两两比较，按相关性聚合信息；擅长长距离依赖和多模态扩展，但计算量、数据量和调参成本通常更高。

### Vision Transformer / Swin

把图像切成 patch 后使用注意力；Swin 用窗口和层级结构降低计算。适合有足够数据或可迁移预训练权重的视觉任务。

### 图神经网络

每个节点反复聚合邻居信息，得到包含局部结构的表示。只有当“谁和谁相连”本身有意义时才值得使用。

### 扩散模型

先逐步加噪，再学习反向去噪生成样本；适合生成、补全、去噪和不确定性建模，但训练和采样成本较高，不能因为“热门”就替代简单插值或树模型。

### 基础模型、LoRA/PEFT、RAG

基础模型提供通用表示；LoRA/PEFT 只训练少量附加参数以降低微调成本；RAG 在回答前检索外部资料。比赛中更常见的落点是调用预训练模型提取特征或做小规模微调。

### Mamba、时间序列基础模型、TabPFN 等

先记住它们试图解决的瓶颈：长序列效率、跨数据集迁移、少样本表格预测。只有当基线和验证方案已经稳定，才把它们作为候选升级项。

## 比赛决策顺序

1. 明确任务和评分函数。
2. 做数据审计：样本数、缺失、异常、重复、时间顺序和标签泄漏。
3. 建立一个可复现的基线。
4. 用与比赛一致的验证方式比较模型。
5. 先做特征和误差分析，再换更复杂的模型。
6. 记录每次实验的配置、随机种子、指标和结论。
7. 最后才做集成、阈值调优和不确定性分析。
