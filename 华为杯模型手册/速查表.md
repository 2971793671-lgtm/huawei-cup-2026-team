# 赛场速查表

## 看到题目先问四件事

1. 目标是预测、分类、聚类、生成，还是求最优决策？
2. 数据是表格、时间序列、文本、图像还是图结构？
3. 评分函数和真实业务代价是什么？
4. 训练集和测试集之间是否存在时间、个体或空间上的泄漏？

## 最小可行模型

- 回归：均值 → 线性回归 → 随机森林/GBDT
- 分类：多数类 → 逻辑回归 → GBDT
- 时间序列：持续性/季节性 → ARIMA/ETS → 滞后特征 + GBDT
- 聚类：标准化 + K-means → GMM/DBSCAN
- 图像：预训练 CNN → 预训练 ViT/Swin
- 文本：TF-IDF + 线性模型 → 预训练 BERT/embedding
- 优化：线性/整数规划 → 启发式算法

## 常见故障定位

| 症状 | 先检查 |
|---|---|
| 训练分数高、验证分数低 | 泄漏、过拟合、切分方式、特征是否包含未来信息 |
| 不同随机种子差异很大 | 样本太少、类别不平衡、模型过大、验证集不稳定 |
| 换大模型没有提升 | 特征质量、评价指标、学习率、预训练权重和数据规模 |
| 时间序列验证异常好 | 是否把未来窗口、全量归一化统计量或目标衍生特征带进训练 |
| 聚类结果无法解释 | 标准化、距离度量、簇数选择和业务变量是否匹配 |

## 每次实验必须记录

日期、数据版本、切分方式、特征版本、模型与超参数、随机种子、指标、运行时间、结论和下一步。
